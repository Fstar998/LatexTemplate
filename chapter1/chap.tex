\noindent 
取消英文字母的连字现象：
\begin{itemize}
\item 使用空的分组(即\{\})
\item 借用$\backslash /$命令
\end{itemize}
\noindent 
连字符、数字范围和破折号:
\begin{itemize}
\item 连字符hyphen：-，如X-ray.
\item 数字范围\footnote{按中文写作习惯，常用$\sim $,使用数学模式：\$$\backslash$sim\$}en dash ：- -，如1--3.
\item 破折号em dash：- - -，如A punctuation dash---like this.
\end{itemize}
\noindent 
省略号：
\begin{itemize}
\item $\backslash$ldots
\item $\backslash$dots
\end{itemize}
空格和换行：
\begin{itemize}
\item 幻影命令$\backslash$phantom\{参数\}：产生与参数内容一样大小的空盒子，没有内容，常用于完成特殊的占位和对齐效果.
\item 水平幻影命令$\backslash$hphantom\{参数\}
\item 垂直幻影命令$\backslash$vphantom\{参数\}
\item $\backslash$$\backslash[2cm]$：其后可带一个可选的长度参数，表示换行后增加的额外垂直间距
\end{itemize}
字体
\begin{itemize}
\item 字号
\item 字体编码
\item 字体族
\begin{enumerate}
\item 罗马字体族\textbackslash textrm\{<文字>\}\& \textbackslash rmfamily
\item 无衬线字体族\textbackslash textsf\{<文字>\}\& \textbackslash sffamily
\item 打印机字体族\textbackslash texttt\{<文字>\}\& \textbackslash ttfamily
\item ctex宏包默认配置了四种字体族：\textbackslash songti、\textbackslash kaishu 、\textbackslash fangsong、 \textbackslash heiti
\end{enumerate}
\item 字体形状
\begin{enumerate}
	\item 直立形状\textbackslash textup\{<文字>\}\& \textbackslash upshade
	\item 意大利形状\textbackslash textit\{<文字>\}\& \textbackslash itshade
	\item 倾斜形状\textbackslash textsl\{<文字>\}\& \textbackslash slshade
	\item 小型大写形状\textbackslash textsc\{<文字>\}\& \textbackslash scshade
\end{enumerate}
\item 字体系列
\begin{enumerate}
	\item 中等\textbackslash textmd\{<文字>\}\& \textbackslash mdseries
	\item 加宽加粗\textbackslash textbf\{<文字>\}\& \textbackslash bfseries
\end{enumerate}
\end{itemize}
